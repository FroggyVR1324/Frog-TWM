## How the Installation Process Works

This process can take up to 5-15 minutes depending on your internet speed and computer performance.

1.  When you run the executable (`frog_twm.exe`) for the first time, it will automatically check for required Python dependencies (like `requests`).
2.  If any dependencies are missing, it will attempt to install them using `pip`.
3.  It will then check for the `frog-twm` model in Ollama.
4.  If the `frog-twm` model is not found locally, it will automatically build it using the embedded configuration (based on Godmoded/llama3-lexi-uncensored:latest).
5.  Once setup is complete (dependencies installed, model built), it will launch the chat interface.

## How to Use FrogTWM

1.  Ensure you have followed the installation steps below (Ollama running).
2.  Run the executable: `frog_twm.exe`.
3.  You will know you are in the chat when you see the FrogTWM logo and the prompt `{your_username}: ` with a blank space above it.
4.  Type your message and press Enter to send it to the AI.
5.  **Important:** If you are pasting multiple lines of text or code, you must press Enter *twice* at the end for it to register and send the full input.

That's it! Enjoy (responsibly)!

## Installation

1.  **Prerequisites:**
    *   Ollama installed and running on your machine.
    *   Download the `frog_twm.exe` file from the [Releases](link-to-your-releases-page-if-you-have-one) section.

2.  **Run the Executable:**
    *   Double-click the `frog_twm.exe` file or run it from the command line: `frog_twm.exe`
    *   The first run will trigger the automatic setup process (checking/installing Python dependencies and building the Ollama model).
