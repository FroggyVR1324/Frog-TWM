## How the Installation Process Works

This process can take up to 5-15 minutes depending on your internet speed and computer performance.

1.  When you run the main script (`frog_twm.py`) for the first time, it will check for dependencies (like Python modules and the Ollama model).
2.  If the `frog-twm` model is not found locally, it will automatically build it using the provided `Modelfile`.
3.  Once setup is complete (dependencies installed, model built), it will launch the chat interface.

## How to Use FrogTWM

1.  Ensure you have followed the installation steps below.
2.  Run the main script: `python frog_twm.py` (or `python3 frog_twm.py`).
3.  You will know you are in the chat when you see the FrogTWM logo and the prompt `{your_username}: ` with a blank space above it.
4.  Type your message and press Enter to send it to the AI.
5.  **Important:** If you are pasting multiple lines of text or code, you must press Enter *twice* at the end for it to register and send the full input.

That's it! Enjoy (responsibly)!

## Installation

1.  **Prerequisites:**
    *   Python 3.x installed.
    *   Ollama installed and running on your machine.
    *   Git (optional, for cloning the repository).

2.  **Clone the Repository (if applicable):**
    ```bash
    git clone https://github.com/your-username/FrogTWM.git
    cd FrogTWM
    ```

3.  **Install Python Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    *(Assuming you create a `requirements.txt` file listing dependencies like `requests` if needed)*

4.  **Run the Script:**
    ```bash
    python frog_twm.py
    ```
    The first run will trigger the automatic setup process (model building).
